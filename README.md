# Productivity Challenger Timer

An Android app for people who delay work until the deadline is at their neck. One
job: start a 2-minute session every day and save proof of it.

- `FEATURES.md` holds the 702-feature plan, the screen map, the daily loop and the
  force stack.
- `BUILD_PROMPT.md` holds the master prompt that builds the app.
- Builds appear under Releases as a debug APK once the Flutter project exists.

## Install on your phone

1. Open the latest release on this repo's Releases page.
2. Download `app-debug.apk` and open it.
3. Allow installs from your browser when Android asks.
